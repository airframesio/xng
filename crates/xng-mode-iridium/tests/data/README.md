# Cross-validation test fixtures

`grtest_prbs15_250k.i16` — the burst from gr-iridium's
`test-data/prbs15-2M-20dB.sigmf-data` (https://github.com/muccc/gr-iridium,
GPL-3; this is *test data* generated by their reference modulator — a
synthetic Iridium frame with a PRBS15 payload at 20 dB channel SNR — used
here as a cross-implementation validation vector, not as ported code),
DDC'd from the original 2 MHz capture to the 250 kHz channel rate
(brickwall ±25 kHz, decimate 8) and trimmed to the 32 ms around the burst,
stored as interleaved I/Q signed 16-bit little-endian.

The demodulated bit stream must begin with the downlink access code and
the payload must satisfy the PRBS15 recurrence x[i] = x[i−15] ⊕ x[i−14]
with zero violations.
